# Roadrunner (Relay)

Roadrunner is an AI-powered engagement tracker built for an AWS Partner Development Manager. Forward emails to Relay and it automatically classifies, links, and summarizes partner engagements, events, and programs. The system uses Claude for intelligent extraction and provides a dashboard to track everything in one place.

Built with Next.js, Supabase, and the Anthropic API. Hosted on Vercel.
